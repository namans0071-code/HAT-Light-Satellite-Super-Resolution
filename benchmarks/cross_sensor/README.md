# Cross-Sensor Generalization (Wald Protocol)

Evaluation scripts for testing zero-shot generalization of the Sentinel-2-trained HAT-Light model on airborne imagery from the USGS National Agriculture Imagery Program (NAIP).

---

## Methodology

Under the Wald protocol:
1. High-resolution 4-channel NAIP imagery (native 0.6m resampled to 2.5m) serves as reference ground truth.
2. Low-resolution inputs are generated by applying a sensor Point Spread Function (PSF) and downsampling 4x to 10m equivalent resolution.
3. The Sentinel-2-trained model performs 4x super-resolution on these inputs without any fine-tuning on NAIP data.

---

## Running Cross-Sensor Evaluation

```bash
python benchmarks/cross_sensor/evaluate_cross_sensor.py \
    --data_dir /path/to/naip_patches \
    --weights weights/best_model.pth
```

Results are documented in `table_cross_sensor.md`.
